# Solutions : avertissement divulgâcheur

Ce dossier contient les solutions complètes de tous les exercices : le code source du défi, l'assembleur de référence, le drapeau (flag) et un corrigé détaillé des deux parties.

Ne l'ouvrez pas avant d'avoir terminé un exercice, ou avant d'avoir sérieusement essayé et de vouloir comparer les approches. Utilisez d'abord les indices du fichier `HINTS.md` de chaque exercice.

Chaque dossier de solution `NN/` contient :

- `src/` : le code source du défi et la compilation qui reproduit le binaire publié.
- `solution.asm` : la solution de référence de la partie Assemble.
- `flag.txt` : le drapeau de la partie Reverse.
- `WRITEUP.md` : le corrigé pas à pas, avec le raisonnement et les impasses.

Les dossiers apparaissent ici à mesure que chaque exercice est terminé.
