# Solutions: spoiler warning

This folder holds the complete solutions for every exercise: the challenge source code, the
reference assembly, the flag and a full write-up of both parts.

Do not open it until you have finished an exercise, or until you have made a serious attempt
and want to compare approaches. Use the hints in each exercise's `HINTS.md` first.

Each solution folder `NN/` contains:

- `src/`: the challenge source and the build that reproduces the published binary.
- `solution.asm`: the reference solution for the Assemble part.
- `flag.txt`: the flag for the Reverse part.
- `WRITEUP.md`: the walkthrough, including reasoning and dead ends.

Folders appear here as each exercise is completed.
