# Soluciones: aviso de spoilers

Esta carpeta contiene las soluciones completas de todos los ejercicios: el código fuente del reto, el ensamblador de referencia, la bandera (flag) y una explicación detallada de ambas partes.

No la abras hasta haber terminado un ejercicio, o hasta haberlo intentado en serio y querer comparar enfoques. Usa primero las pistas del archivo `HINTS.md` de cada ejercicio.

Cada carpeta de solución `NN/` contiene:

- `src/`: el código fuente del reto y la compilación que reproduce el binario publicado.
- `solution.asm`: la solución de referencia de la parte Assemble.
- `flag.txt`: la bandera de la parte Reverse.
- `WRITEUP.md`: la explicación paso a paso, con el razonamiento y los callejones sin salida.

Las carpetas aparecen aquí a medida que se completa cada ejercicio.
