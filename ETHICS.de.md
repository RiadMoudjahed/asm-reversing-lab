# Ethik und verantwortungsvolle Nutzung

Reverse Engineering ist eine legitime und wertvolle Fähigkeit. Sie wird eingesetzt, um Systeme interoperabel zu machen, Software auf Sicherheitsprobleme zu prüfen, Schadcode zu analysieren, damit Menschen geschützt werden können, Wissen über unzureichend dokumentierte Systeme zurückzugewinnen und zu verstehen, wie Computer funktionieren. Dieselbe Fähigkeit kann missbraucht werden. Diese Seite legt dar, wie dieses Projekt ihre Nutzung erwartet.

## Was dieser Kurs vermittelt und was nicht

- Er vermittelt, wie man Code auf Maschinenebene liest und schreibt und wie man Programme analysiert, die dieses Repository bereitstellt.
- Er vermittelt keine Exploit-Entwicklung, keinen Shellcode und keine Entwicklung von Schadsoftware.
- Er vermittelt nicht, wie man Kopierschutz, Lizenzierung oder digitale Rechteverwaltung umgeht.
- Programme, die verdächtiges Verhalten nachahmen, etwa die Beispiele im Modul zur Schadsoftware-Analyse, sind Simulatoren. Sie geben nur aus, was sie tun würden, und führen es nie aus.

## Ihre Verantwortung

1. **Analysieren Sie nur, was Sie analysieren dürfen.** Das sind selbst geschriebene Software, Software mit einer offenen Lizenz, die dies erlaubt, von diesem Kurs bereitgestellte Programme und Systeme, für die Sie eine ausdrückliche schriftliche Erlaubnis haben.
2. **Kennen Sie Ihr lokales Recht und Ihre Lizenzen.** Regeln zu Dekompilierung, Umgehung und Sicherheitsforschung unterscheiden sich zwischen Ländern und Lizenzverträgen. So erlaubt etwa die EU-Richtlinie 2009/24/EG die Dekompilierung zur Herstellung der Interoperabilität unter strengen Bedingungen, während andere Rechtsordnungen die Umgehung technischer Schutzmaßnahmen einschränken. Diese Seite ist keine Rechtsberatung; ziehen Sie im Zweifel eine qualifizierte Fachperson hinzu.
3. **Isolieren Sie riskante Arbeit.** Verwenden Sie den Lab-Container oder eine virtuelle Maschine für alles Unbekannte. Führen Sie unbekannte Programme nicht auf einem Rechner aus, der private oder berufliche Daten enthält.
4. **Melden Sie verantwortungsvoll.** Finden Sie eine Schwachstelle in fremder Software, melden Sie sie vertraulich dem Hersteller oder Maintainer, geben Sie angemessen Zeit zur Reaktion und veröffentlichen Sie keine Details, die Nutzer gefährden.
5. **Respektieren Sie Menschen.** Nutzen Sie Gelerntes niemals, um jemandem zu schaden, jemanden zu belästigen, auszuspionieren oder zu betrügen.
