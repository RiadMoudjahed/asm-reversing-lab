# Ethics and Responsible Use

Reverse engineering is a legitimate and valuable skill. It is used to make systems
interoperate, to audit software for security problems, to analyze malicious code so people
can be protected, to recover knowledge about systems that lack documentation, and to learn how
computers work. The same skill can be misused. This page sets out how this project expects you
to use it.

## What this course teaches and what it does not

- It teaches how to read and write machine-level code and how to analyze programs that this
  repository provides.
- It does not teach exploit development, shellcode or malware development.
- It does not teach how to defeat copy protection, licensing or digital rights management.
- Programs that imitate suspicious behavior, such as the samples in the malware-analysis
  module, are simulators. They only print what they would do and never perform it.

## Your responsibilities

1. **Analyze only what you have the right to analyze.** That means software you wrote,
   software that is openly licensed in a way that permits it, programs provided by this
   course, and systems for which you have explicit written permission.
2. **Know your local law and your licenses.** Rules about decompilation, circumvention and
   security research differ between countries and between license agreements. For example,
   EU Directive 2009/24/EC allows decompilation for interoperability under strict conditions,
   while other jurisdictions restrict circumvention of technical protection measures. This
   page is not legal advice; consult a qualified professional when in doubt.
3. **Isolate risky work.** Use the lab container or a virtual machine for anything unknown.
   Do not run unknown programs on a machine that holds personal or work data.
4. **Disclose responsibly.** If you find a vulnerability in someone else's software, report it
   privately to the vendor or maintainer, give them reasonable time to respond, and do not
   publish details that put users at risk.
5. **Respect people.** Never use what you learn to harm, harass, spy on or defraud anyone.

## For contributors

Content that falls outside these boundaries will not be accepted. See
[CONTRIBUTING.md](CONTRIBUTING.md) for the ground rules.
