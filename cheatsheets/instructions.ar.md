# التعليمات الشائعة

صيغة Intel: الوجهة أولاً. عمود الرايات: الرايات التي تغيّرها التعليمة.

## نقل البيانات

| التعليمة | الأثر | الرايات |
|---|---|---|
| `mov d, s` | ينسخ `s` إلى `d` | لا يوجد |
| `movzx d, s` | نسخ مع تمديد بالأصفار | لا يوجد |
| `movsx d, s` | نسخ مع تمديد الإشارة | لا يوجد |
| `lea d, [m]` | يحمّل العنوان `m` دون قراءة الذاكرة | لا يوجد |
| `xchg a, b` | يبدّل `a` و`b` | لا يوجد |
| `push s` | ينقص `rsp` ويخزّن `s` | لا يوجد |
| `pop d` | يحمّل `d` من المكدس ويزيد `rsp` | لا يوجد |

## الحساب والمنطق

| التعليمة | الأثر | الرايات |
|---|---|---|
| `add d, s` / `sub d, s` | الجمع والطرح | كل الرايات الحسابية |
| `adc d, s` / `sbb d, s` | جمع أو طرح مع الحمل | كل الرايات الحسابية |
| `inc d` / `dec d` | جمع 1 أو طرحه | كلها عدا `CF` |
| `neg d` | النفي بمتمم الاثنين | كل الرايات الحسابية |
| `imul d, s` | ضرب بإشارة، مبتور | `CF`, `OF` |
| `mul s` / `div s` | ضرب أو قسمة بلا إشارة باستخدام `rax` و`rdx` | يختلف |
| `idiv s` | قسمة بإشارة باستخدام `rax` و`rdx` | غير معرّفة |
| `and`, `or`, `xor`, `not` | عمليات على مستوى البتات (لا تغيّر `not` الرايات) | `ZF` و`SF` و`PF`؛ وتُصفَّر `CF` و`OF` |
| `shl`, `shr`, `sar` | إزاحة لليسار، ولليمين منطقية، ولليمين حسابية | `CF`, `ZF`, `SF`, `PF` |
| `rol`, `ror` | تدوير | `CF`, `OF` |
| `cmp a, b` | يحسب `a - b` ويحتفظ بالرايات فقط | كل الرايات الحسابية |
| `test a, b` | يحسب `a & b` ويحتفظ بالرايات فقط | `ZF`, `SF`, `PF` |

## التحكم في التدفق

| التعليمة | الأثر |
|---|---|
| `jmp t` | يقفز إلى `t` |
| `je` / `jne` | يقفز إذا تساويا / لم يتساويا (`ZF`) |
| `ja` / `jb` / `jae` / `jbe` | يقفز إذا كان أكبر / أصغر، بلا إشارة (`CF` و`ZF`) |
| `jg` / `jl` / `jge` / `jle` | يقفز إذا كان أكبر / أصغر، بإشارة (`SF` و`OF` و`ZF`) |
| `js` / `jns` | يقفز إذا كانت الإشارة مضبوطة / مصفّرة |
| `call t` | يدفع عنوان العودة ويقفز إلى `t` |
| `ret` / `ret N` | يسحب عنوان العودة إلى `rip`؛ وتزيل `ret N` أيضاً `N` بايتاً |
| `loop t` | ينقص `rcx` ويقفز إذا لم يكن صفراً |

## تعليمات السلاسل

| التعليمة | الأثر |
|---|---|
| `movs`, `stos`, `lods` | نسخ، وتخزين `al`/`ax`/`eax`/`rax`، وتحميل فيه |
| `cmps`, `scas` | مقارنة معاملين في الذاكرة، ومقارنة الذاكرة بـ `al`/`ax`/`eax`/`rax` |
| `rep`, `repe`, `repne` | يكرر ما دامت `rcx` غير صفر (وما دامت `ZF` مضبوطة أو مصفّرة في `repe` و`repne`) |
| `cld` / `std` | تصفير راية الاتجاه أو ضبطها |

## النظام

| التعليمة | الأثر |
|---|---|
| `syscall` | استدعاء النظام (64 بت) |
| `int 0x80` | استدعاء النظام في Linux (32 بت) |
| `nop` | لا يفعل شيئاً |
| `leave` | `mov rsp, rbp` ثم `pop rbp` |
