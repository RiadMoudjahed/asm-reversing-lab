# ELF

الصيغة التنفيذية في Linux. الدرس: [12. الصيغ التنفيذية: ELF وPE](../modules/12-executable-formats/README.ar.md).

## بنية الملف

| الجزء | الموضع | يستخدمه |
|---|---|---|
| ترويسة ELF | الإزاحة 0، و64 بايتاً في ملف 64 بت | كل شيء |
| جدول ترويسات البرنامج | عند `e_phoff`، وعادة 64 | المحمّل |
| بيانات الأقسام | بين الجدولين | كلاهما |
| جدول ترويسات الأقسام | عند `e_shoff`، وعادة في النهاية | الرابط ومصحح الأخطاء ومحلل الهندسة العكسية (غير لازم للتشغيل) |

يقرأ المحمّل ترويسات البرنامج فقط. والملف الذي أُزيلت ترويسات أقسامه يعمل مع ذلك.

## حقول ترويسة ELF (64 بت)

| الإزاحة | الحجم | الحقل | المعنى |
|---|---|---|---|
| 0 | 4 | الرقم السحري `e_ident` | `7f 45 4c 46` (`\x7fELF`) |
| 4 | 1 | الصنف | 1 = 32 بت، 2 = 64 بت |
| 5 | 1 | البيانات | 1 = little endian، 2 = big endian |
| 16 | 2 | `e_type` | 2 = EXEC، 3 = DYN (كائن مشترك أو ملف تنفيذي مستقل عن الموضع) |
| 18 | 2 | `e_machine` | 3 = x86, 62 = x86-64 |
| 24 | 8 | `e_entry` | العنوان الافتراضي لأول تعليمة |
| 32 | 8 | `e_phoff` | إزاحة جدول ترويسات البرنامج في الملف |
| 40 | 8 | `e_shoff` | إزاحة جدول ترويسات الأقسام في الملف |
| 54 | 2 | `e_phentsize` | حجم ترويسة برنامج واحدة (56) |
| 56 | 2 | `e_phnum` | عدد ترويسات البرنامج |
| 58 | 2 | `e_shentsize` | حجم ترويسة قسم واحدة (64) |
| 60 | 2 | `e_shnum` | عدد ترويسات الأقسام |
| 62 | 2 | `e_shstrndx` | فهرس القسم الذي يحوي أسماء الأقسام |

## أنواع ترويسات البرنامج

| النوع | المعنى |
|---|---|
| `PT_LOAD` | نطاق من الملف يُربط بالذاكرة: إزاحة الملف والعنوان الافتراضي وحجم الملف وحجم الذاكرة والأذونات |
| `PT_INTERP` | مسار المحمّل الديناميكي |
| `PT_DYNAMIC` | القسم الديناميكي: المكتبات المطلوبة وجداول إعادة تحديد المواقع |
| `PT_NOTE` | ملاحظات مثل معرّف البناء |
| `PT_GNU_STACK` | أذونات المكدس |
| `PT_GNU_RELRO` | نطاق يصبح للقراءة فقط بعد إعادة تحديد المواقع |

المقطع الذي يزيد حجمه في الذاكرة على حجمه في الملف يُملأ بالأصفار بعد بيانات الملف. وبهذا لا يشغل `.bss` مكاناً في الملف.

## الأقسام الشائعة

| القسم | المحتوى |
|---|---|
| `.text` | الشيفرة |
| `.rodata` | بيانات للقراءة فقط وحروف السلاسل النصية الثابتة |
| `.data` | بيانات مهيأة قابلة للكتابة |
| `.bss` | بيانات مهيأة بالصفر ولا بايتات لها في الملف |
| `.plt`, `.plt.sec` | شيفرات وسيطة تقفز عبر GOT |
| `.got`, `.got.plt` | عناوين يملؤها المحمّل الديناميكي |
| `.dynsym`, `.dynstr` | رموز وأسماء مطلوبة وقت التحميل |
| `.symtab`, `.strtab` | جدول الرموز الكامل؛ يزيله `strip` |
| `.rela.dyn`, `.rela.plt` | مدخلات إعادة تحديد المواقع |
| `.init_array`, `.fini_array` | دوال تعمل قبل `main` وعند الخروج |
| `.eh_frame` | معلومات فك المكدس |

## الاستدعاءات الديناميكية

يذهب استدعاء دالة مكتبة إلى شيفرة وسيطة في PLT. وتقفز هذه الشيفرة عبر مدخل في GOT. ومع الربط المتأخر يصل الاستدعاء الأول إلى المحمّل الديناميكي، فيحل الاسم ويكتب العنوان الحقيقي في مدخل GOT؛ وتذهب الاستدعاءات اللاحقة إليه مباشرة. والملف المربوط بالخيار `-z now` يحل كل شيء عند البدء.

## الأوامر

</div>

```bash
file prog                    # kind, bits, stripped or not
readelf -h prog              # ELF header
readelf -lW prog             # program headers and the section-to-segment map
readelf -SW prog             # section headers
readelf -sW prog             # symbol tables
readelf -dW prog             # dynamic section (needed libraries)
readelf -rW prog             # relocations
objdump -d -M intel prog     # disassemble code sections
objdump -s -j .rodata prog   # hex dump of one section
nm -D prog                   # dynamic symbols
ldd prog                     # libraries the loader would bring in
strings -a -t x prog         # printable strings with file offsets
```

## التحويلات

- إزاحة الملف لعنوان داخل مقطع `PT_LOAD`: `offset = address - p_vaddr + p_offset`.
- افحص المقطع لا القسم عندما يختلفان. فالمحمّل يستخدم المقاطع.
- يُحمَّل الملف التنفيذي المستقل عن الموضع (`e_type` 3) عند قاعدة عشوائية. والعناوين في الملف نسبية إلى تلك القاعدة.
