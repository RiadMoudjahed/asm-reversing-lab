# Rizin

مفكك تجميع وإطار تحليل بسطر الأوامر. الدرس: [11. صندوق أدوات من يمارس الهندسة العكسية](../modules/11-toolkit/README.ar.md). نُفّذت الأوامر أدناه على صورة المختبر.

## البدء

| سطر الأوامر | الأثر |
|---|---|
| `rizin prog` | الفتح بشكل تفاعلي |
| `rizin -A prog` | الفتح وتحليل كل شيء |
| `rizin -q -e scr.color=0 -A -c "CMDS" prog` | تنفيذ أوامر تفصل بينها `;` وطباعة نص عادي ثم الخروج |
| `rizin -d prog` | الفتح تحت مصحح الأخطاء |

## نمط الأوامر

الأوامر كلمات قصيرة من حرف العائلة وفعل. أضف `?` لترى مساعدة بادئة: `a?` و`p?` و`i?`. وأضف `@ ADDR` أو `@ sym.name` لتنفيذ أمر في موضع آخر، و`~TEXT` للإبقاء على الأسطر التي تحوي `TEXT` فقط.

## التحليل

| الأمر | المعنى |
|---|---|
| `aaa` | تحليل كل شيء (الخيار `-A` يفعل ذلك عند الفتح) |
| `afl` | عرض الدوال مع العنوان وعدد الكتل والحجم |
| `afvl @ sym.check` | عرض وسائط الدالة ومتغيراتها المحلية |
| `axt @ sym.check` | من يشير إلى هذا العنوان (المستدعون) |
| `afn NAME @ ADDR` | إعادة تسمية دالة |

## الطباعة

| الأمر | المعنى |
|---|---|
| `pdf @ sym.check` | تفكيك دالة كاملة |
| `pd 3 @ ADDR` | تفكيك 3 تعليمات |
| `px 16 @ 0x402038` | تفريغ سداسي عشري لـ 16 بايتاً |
| `ps ascii @ ADDR` | طباعة سلسلة ASCII منتهية بصفر (`ps` البسيط يخمّن الترميز وقد يطبع نصاً مشوشاً) |
| `s ADDR` | نقل الموضع الحالي |

## المعلومات

| الأمر | المعنى |
|---|---|
| `iI` | ملخص الملف التنفيذي: الصيغة وعدد البتات والحمايات |
| `iS` | الأقسام مع الإزاحات والعناوين والأذونات |
| `is` | الرموز (`is~check` يرشّح) |
| `ii` | الاستيرادات |
| `iz` | السلاسل النصية في أقسام البيانات |
| `izz` | السلاسل النصية في الملف كله |
| `ie` | نقاط الدخول (البرنامج وinit وfini) |

## ملاحظات على الخرج

- يزيل `scr.color=0` رموز الألوان حين تنسخ الخرج إلى ملف.
- يستغرق `-A` وقتاً مع الملفات الكبيرة. وللمحة سريعة افتح بدونه ونفّذ `af` عند عنوان.
- يسمي Rizin الأشياء ببادئات: `sym.` للدوال و`obj.` للبيانات و`sym.imp.` للاستيرادات و`str.` للسلاسل النصية.
