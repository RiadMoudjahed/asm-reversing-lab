# GDB

مصحح أخطاء GNU. الدرس: [11. صندوق أدوات من يمارس الهندسة العكسية](../modules/11-toolkit/README.ar.md). كل أمر أدناه نُفّذ على صورة المختبر.

## البدء

| سطر الأوامر | الأثر |
|---|---|
| `gdb prog` | تحميل برنامج |
| `gdb --args prog a b` | تحميله مع وسائط |
| `gdb -nx -q -batch -ex "CMD" prog` | تنفيذ أوامر بدون إضافات وطباعة نص عادي (للملاحظات والنصوص البرمجية) |
| `gdb -p PID` | الارتباط بعملية قيد التشغيل |

داخل GDB يبدأ `run ARGS` البرنامج ويتوقف `start` عند بداية `main` حين توجد الرموز. ويخرج `quit`.

## نقاط التوقف ونقاط المراقبة

| الأمر | المعنى |
|---|---|
| `break check`, `b *0x401184` | التوقف عند دالة أو عند عنوان محدد |
| `tbreak check` | التوقف مرة واحدة ثم حذف نقطة التوقف |
| `info breakpoints` | عرض نقاط التوقف وعدد مرات بلوغها |
| `delete N`, `disable N`, `enable N` | حذف نقطة التوقف `N` أو تعطيلها أو تفعيلها |
| `condition N EXPR` | التوقف عند نقطة التوقف `N` فقط حين يكون `EXPR` صحيحاً |
| `watch EXPR`, `watch *(int *)$rsp` | التوقف عند تغيّر قيمة |
| `rwatch EXPR`, `awatch EXPR` | التوقف عند قراءة، أو عند قراءة أو كتابة |

البرنامج المجرَّد من الرموز لا أسماء دوال فيه. استخدم العنوان (`b *0x401184`) أو نقطة الدخول (`info files` ثم `b *ADDR`).

## التشغيل

| الأمر | المعنى |
|---|---|
| `continue` | المتابعة |
| `stepi`, `nexti` | تعليمة واحدة، مع الدخول في الاستدعاءات أو تجاوزها |
| `step`, `next` | سطر مصدري واحد (يحتاج إلى معلومات تنقيح) |
| `finish` | التشغيل حتى تعود الدالة الحالية |
| `until ADDR` | التشغيل حتى بلوغ عنوان |
| `call EXPR` | استدعاء دالة في البرنامج |
| `set var X = V`, `set $rax = 0` | تغيير متغير أو سجل |
| `jump *ADDR` | المتابعة عند عنوان آخر |

## النظر في الحالة

| الأمر | المعنى |
|---|---|
| `info registers`, `info registers rdi` | كل السجلات، أو المسماة منها |
| `print EXPR`, `p/x $rsp` | تقييم؛ `/x` سداسي عشري و`/d` عشري و`/t` ثنائي و`/c` حرف |
| `x/NFU ADDR` | فحص الذاكرة: `N` وحدة بصيغة `F` وحجم وحدة `U` |
| `bt` | مكدس الاستدعاءات |
| `info frame` | الإطار عند التوقف الحالي |
| `info proc mappings` | خريطة ذاكرة العملية |
| `info functions REGEX` | الدوال المطابقة لنمط |
| `disassemble check` | تفكيك دالة |
| `display/i $pc` | عرض التعليمة التالية عند كل توقف |

### صيغ ووحدات `x`

| الحرف | المعنى |
|---|---|
| `x`, `d`, `u`, `o`, `t` | سداسي عشري، بإشارة، بلا إشارة، ثماني، ثنائي |
| `c`, `s` | حروف، سلسلة نصية |
| `i` | التعليمات |
| `b`, `h`, `w`, `g` | حجم الوحدة: 1 أو 2 أو 4 أو 8 بايتات |

أمثلة: `x/4gx $rsp` أربع كلمات بحجم 8 بايتات بالسداسي العشري، و`x/s $rdi` السلسلة عند `rdi`، و`x/5i $pc` خمس تعليمات ابتداءً من الحالية.

## إعدادات تستحق المعرفة

| الأمر | المعنى |
|---|---|
| `set disassembly-flavor intel` | صياغة Intel (تضبطها صورة المختبر) |
| `set args A B` | وسائط التشغيل التالي لـ `run` |
| `set disable-randomization on` | عناوين ثابتة (الافتراضي خارج الحاويات) |
| `set logging enabled on` | نسخ الخرج إلى `gdb.txt` |
| `set confirm off` | بلا أسئلة تأكيد |

## GEF

تحمّل صورة المختبر الإضافة GEF التي تطبع السجلات والمكدس والشيفرة بعد كل توقف. أوامر مفيدة:

| الأمر | المعنى |
|---|---|
| `context` | إعادة رسم عرض السجلات والمكدس والشيفرة |
| `vmmap` | خريطة الذاكرة مع الأذونات |
| `checksec` | حمايات الملف المحمّل |
| `telescope $rsp 8` | كلمات المكدس مع القيم التي تشير إليها |
| `search-pattern TEXT` | البحث عن بايتات في الذاكرة |

استخدم `gdb -nx` حين تحتاج إلى خرج عادي.

## تذكيرات

- يتغير عنوان المكدس في `rdi` أو `rsp` من تشغيل إلى آخر. لا تنسخه إلى ملاحظاتك على أنه حقيقة.
- بعد `finish` تكون النتيجة في `rax`.
- داخل حاوية يكون التحذير "Error disabling address space randomization" طبيعياً.
