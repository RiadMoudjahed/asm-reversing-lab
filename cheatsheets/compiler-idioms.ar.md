# أنماط المترجم

ما تنتجه المترجمات المحسِّنة لتراكيب C الشائعة وكيف تقرؤه عائداً. الدروس: [13. التعرف على بنى الشيفرة](../modules/13-code-structures/README.ar.md) و[14. الحساب المترجم](../modules/14-compiled-arithmetic/README.ar.md) و[15. استعادة البيانات](../modules/15-recovering-data/README.ar.md). الأمثلة شيفرة 32 بت بـ `int` و`unsigned` لمعمارية x86-64 System V، والوسيط الأول في `edi`.

## شكل الدالة

| النمط | ما يخبرك به |
|---|---|
| `push rbp; mov rbp, rsp` ... `pop rbp` أو `leave` | مؤشر إطار: شيفرة غير محسَّنة، أو منطقة مكدس متغيرة الحجم |
| تعليمات push لـ `rbx` و`rbp` و`r12` إلى `r15` في البداية | قيم تعيش عبر الاستدعاءات |
| `sub rsp, N` | مكان للمتغيرات المحلية أو المؤقتات المحفوظة أو المحاذاة |
| بلا مقدمة وتنتهي بـ `ret` | دالة ورقية |
| تنتهي بـ `jmp` إلى دالة أخرى | استدعاء ذيلي: تعود الدالة المستدعاة إلى مستدعي المستدعي |
| جسم دالة منسوخ في المستدعي | تضمين مباشر؛ ابحث عن استدعاء مفقود |

## تدفق التحكم

| الدليل | المصدر |
|---|---|
| `cmp` / `jcc` فوق كتلة | `if` |
| كتلتان مع `jmp` فوق الثانية | `if` / `else` |
| عدة `jcc` إلى وسم "false" واحد، والنجاح يتابع من الأسفل | شروط مربوطة بـ `&&` |
| `jcc` إلى وسم "true" واختبار أخير يقفز بعيداً عند false | شروط مربوطة بعامل OR |
| `jmp test` في البداية والاختبار في الأسفل مع `jcc` إلى الخلف | `for` / `while`، غير محسَّنة |
| حارس يتجاوز الحلقة ثم الجسم ثم `jcc` إلى الخلف | `for` / `while`، محسَّنة |
| الجسم أولاً و`jcc` إلى الخلف فقط | `do` / `while` |
| `jmp` غير مشروط إلى الخلف مع مخرج في الجسم | حلقة لا نهائية |

## Switch

| الدليل | ما هو |
|---|---|
| عدة `cmp reg, constant / je` متتالية | سلسلة مقارنات |
| `cmp reg, N / ja default` ثم `jmp` غير مباشر عبر `[reg*8 + table]` | جدول قفز بـ N + 1 مدخلاً |
| `cmp reg, N / ja default` ثم تحميل من مصفوفة | جدول بحث |
| `cmp` بثابت أوسط ثم `je` و`jg`، مكررة | بحث ثنائي |

## الضرب في ثابت

| الثابت | شيفرة نموذجية |
|---|---|
| 2, 4, 8 | `shl` أو `lea eax, [rdi*8]` |
| 3, 5, 9 | `lea eax, [rdi+rdi*2]`, `[rdi+rdi*4]`, `[rdi+rdi*8]` |
| 2^n - 1 (7, 15, 31) | `shl` ثم `sub` للأصل |
| 2^n + 1 (17, 33) | `shl` ثم `add` للأصل |
| 6, 10, 12 | `lea` ثم `add` أو `shl` |
| -1, -3 | `neg` أو `sub` من قيمة مضروبة |
| كبير أو غير منتظم | `imul reg, reg, constant` |

يحسب `lea` القيمة `base + index*scale + displacement` (العامل 1 أو 2 أو 4 أو 8) دون قراءة الذاكرة ودون تغيير الرايات. و`lea` الذي لا يُستخدم ناتجه عنواناً أبداً هو حساب.

## القسمة والباقي على ثابت

| التسلسل | العملية |
|---|---|
| `shr reg, k` | قسمة بلا إشارة على 2^k |
| `and reg, 2^k - 1` | باقٍ بلا إشارة بترديد 2^k |
| `shr 31` و`add` و`sar` أو `lea` و`test` و`cmovns` و`sar` | قسمة بإشارة على قوة للعدد 2 (تضيف انحيازاً قدره 2^k - 1 إلى القيم السالبة) |
| `sar 31`, `shr 32-k`, `add`, `and`, `sub` | باقٍ بإشارة لقوة للعدد 2 (ليس أبداً `and` مجرداً) |
| `imul` بثابت فردي كبير ثم `shr` | قسمة بلا إشارة على ثابت |
| الصيغة نفسها مع `sar 31` و`sub` | قسمة بإشارة على ثابت |
| `sub` و`shr` و`add` و`shr` بعد الضرب العالي | قسمة على ثابت يحتاج رقمه السحري إلى 33 بتاً (مثل 7) |
| `x - (x / d) * d` باستخدام التسلسلات أعلاه | باقٍ على ثابت |
| `cdq`, `idiv` | قسمة بإشارة على متغير |
| `xor edx, edx`, `div` | قسمة بلا إشارة على متغير |

استعادة المقسوم عليه: المقسوم عليه = 2^shift / magic، مقرَّباً إلى أقرب عدد صحيح. يفعل ذلك النص `modules/14-compiled-arithmetic/examples/14_magic.py` ويتحقق منه.

## شيفرة بلا قفزات

| التسلسل | المعنى |
|---|---|
| `xor eax, eax` / `test` / `sete al` | `x == 0` بقيمة 0 أو 1 |
| `cmp` / `setl` أو `setb` | مقارنة بقيمة 0 أو 1 |
| `neg` / `cmovs` | القيمة المطلقة |
| `cmp a, b` / `sbb reg, reg` | كل البتات واحد إذا كان `a < b` بلا إشارة، وإلا 0 |
| `cmp` / `cmovge` أو `cmovnb` | أكبر قيمتين |

## بإشارة أو بلا إشارة

| | بإشارة | بلا إشارة |
|---|---|---|
| قفزة بعد مقارنة | `jl`, `jle`, `jg`, `jge` | `jb`, `jbe`, `ja`, `jae` |
| ضبط من مقارنة | `setl`, `setg` | `setb`, `seta` |
| نقل مشروط | `cmovl`, `cmovge` | `cmovb`, `cmovae` |
| إزاحة لليمين | `sar` | `shr` |
| التوسيع إلى 64 بتاً | `movsx` أو `movsxd` | `mov` إلى سجل من 32 بتاً |
| القسمة | `cdq` / `idiv` | `xor edx, edx` / `div` |

## البيانات

| الدليل | المعنى |
|---|---|
| عدة وصولات عند إزاحات ثابتة من مؤشر واحد | بنية؛ والإزاحات هي حقولها |
| `[base + index*scale]` | مصفوفة عناصرها بحجم `scale` |
| وصول بإزاحة ثابتة وفهرس | مصفوفة داخل بنية |
| استدعاء المخصِّص بحجم ثابت | حجم بنية |
| مؤشر مخزَّن عند إزاحة في بنية يُحمَّل ويُتبَع في حلقة | قائمة مترابطة أو شجرة |
| تخزين عنوان ثابت في أول كلمة من كائن جديد | مؤشر vtable (C++): يشير العنوان إلى ما بعد معلومات النوع |
| `call [rax + 8*n]` بعد تحميل `rax` من `[rdi]` | استدعاء افتراضي، الخانة `n` |
